# Демо-vault для Lab 1

Окреме сховище Obsidian тільки для демонстрації агента-планувальника походів Пласту.
Тут немає особистих нотаток. Відкривати в Obsidian як окремий vault (Open folder as vault → ця папка).

- `Запити/`: що хоче провідник (група, вік, дати, район, побажання). Агент читає звідси.
- `Правила/`: норми безпеки й вимоги Пласту, які агент перевіряє. [VERIFY: внести справжні норми]
- `Плани/`: сюди агент записує готовий план походу з перевірками та висновками.
