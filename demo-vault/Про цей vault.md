# Демо-vault для Lab 1

Окреме сховище Obsidian тільки для демонстрації агента-планувальника походів Пласту.
Тут немає особистих нотаток; усі дані вигадані. Відкривати в Obsidian як окремий vault (Open folder as vault → ця папка).

- `Запити/`: що хоче провідник (група, вік, дати, район, побажання, обмеження групи). Агент читає звідси.
- `Плани/`: сюди агент записує готовий план походу з перевірками, погодою, запасами й журналом рішень.

Норми безпеки Пласту не лежать у vault: їх застосовує сервер `plast-trail` з файлу `data/rules.yaml`
(чернетка з джерелами, див. `research/rules-for-approval.md`). Обмеження конкретної групи пишуться в запиті.
