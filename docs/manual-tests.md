# Ручні перевірки перед захистом

Те, що автоматичні тести перевірити не можуть: як усе виглядає в Obsidian, у браузері й у телефоні.
Кожна перевірка — це команда, що ввести і що має вийти. Позначай ✅ або пиши, що пішло не так.

## Перед початком (щоразу)
1. Відкрий **Obsidian** з vault **demo-vault**.
2. Запусти сервер plast-trail в окремій вкладці Термінала (не закривай її):
   ```bash
   cd "/Users/nazarobod/Desktop/Second Brain/01-Education/kse-agentic-ai-school/assignments/lab1-mcp-integration/plast-hike-planner"
   uv run plast-trail
   ```
3. Для перевірок із локальною моделлю відкрий застосунок **Ollama** (іконка ламы вгорі на екрані).
4. Усі команди агента — в іншій вкладці Термінала, після того самого `cd`.

---

## 1. Автоматичні тести (1 хвилина, без моделі)
```bash
uv run pytest -q
```
- [ ] Має бути **`123 passed`** (або більше, якщо додамо тести).

## 2. Діалог з хмарною моделлю (інтернет є)
```bash
uv run plast-agent --chat
```
Напиши: «Нас троє друзів, усім по 20, хочемо на Говерлу 28 листопада на 2 дні» → Enter двічі.
- [ ] Агент **не перепитує** групу, кількість і дорослих (усе є в тексті).
- [ ] «Ось що я зрозумів»: старші, вас 3, дорослих 0, 2 дні, 28.11, місця: Говерла.
- [ ] В Obsidian у «Плани» з'явилась нотатка плану, а в ній:
  - [ ] **малюнок** (схема, картки днів, профіль висот із кольорами крутизни);
  - [ ] посилання **«Увесь маршрут · день 1 · день 2»** на Mapy.com;
  - [ ] **інтерактивна карта** з топокартою, червоною лінією треку й позначками.
- [ ] У Терміналі в кінці: «Готово: … виклики LLM: 3–6 · діалог N с, планування M с».
- [ ] Маршрут на Говерлу закінчується на вершині: у плані попередження **«маршрут закінчується на висоті …, а спуску
  в плані немає»** з порадою, скільки йти вниз і о котрій будете назад.

## 3. Локальна модель (без хмарного ліміту)
```bash
uv run plast-agent --chat --local
```
Той самий запит.
- [ ] Угорі: «Модель: лише локальна (Ollama готова: plast-gemma)».
- [ ] Увесь запуск займає менше хвилини, ноут не перегрівається.
- [ ] Результат такий самий, як у перевірці 2.
- [ ] Після тесту: `ollama stop plast-gemma` (звільняє пам'ять).

## 4. Без інтернету
1. Вимкни **Wi-Fi** (значок угорі праворуч).
2. Запусти `uv run plast-agent --chat --local` з будь-яким запитом.
- [ ] План складається й записується в Obsidian (нічого з інтернету не потрібно: маршрути, норми, погода
  в режимі replay і локальна модель — усе на ноуті).
- [ ] В Obsidian **малюнок** видно повністю.
- [ ] **Інтерактивна карта**: без інтернету підкладка (топокарта) не завантажиться, але **червона лінія треку
  й позначки** мають бути на сірому фоні.
- [ ] Посилання Mapy.com без інтернету не відкриваються — це нормально.
3. Увімкни Wi-Fi, закрий і знову відкрий нотатку: топокарта з'являється.

## 5. Мало дорослих
`--chat`: «планую піти я з юнацтвом, 7 хлопців, на 2 дні з 23 листопада, Чорногора».
- [ ] Угорі плану: **«✅ План готовий · за можливості візьміть ще дорослого на супровід»** (не «failed»).
- [ ] Є повний план: погода, запаси, малюнок, карта.

## 6. Назва з помилкою
`--chat`: «старші, нас двоє, 2 дні з 23 листопада, хочемо на піпівана».
- [ ] «Ось що я зрозумів» містить **«піпівана» → Піп Іван Чорногірський**.
- [ ] Маршрут проходить через Піп Іван.

## 7. Місце, через яке не проходить жоден маршрут
`--chat`: «юнацтво, 7 хлопців і 2 виховники, на бребенеско, 2 дні з 23 листопада».
- [ ] Примітка: **«Через Бребенескул не проходить жоден маршрут… Найближче підходить … — N км»**.
- [ ] На малюнку й на карті Бребенескул позначено (на малюнку зірочкою з пунктиром).
- [ ] Є посилання **«⭐ Радіальний вихід: Бребенескул»**.
- [ ] Розділ **«Інші варіанти маршруту»** з таблицею.

## 8. «Не важливо» в діалозі
`--chat`: «гурток 10 хлопців 11-13 років». На питання про дорослих: «2». Про дні: «не важливо, хочемо вийти 19 листопада».
- [ ] Про дату агент **не питає** (взяв з відповіді про дні).
- [ ] «⚠️ Днів: 2 — моє припущення».
- [ ] Між відповідями **немає** «Думаю над запитом…» (відповіді розбирає код, без запиту до моделі).

## 8а. Місце, яке модель могла пропустити
`--chat --local`: «на вихідних ідемо курінем у Свидовець, 11 юнаків 15-16 років і 2 провідники, хочемо на Близницю,
ночувати біля джерела».
- [ ] «Ось що я зрозумів» містить **місця: Близниця** (і, можливо, «⚠️ Місце з тексту: Близниця»).
- [ ] Час виходу 08:00 (не 20:00), навіть якщо запускаєш цей запит удруге.

## 9. Інтерактивна карта в Obsidian
У будь-якому плані:
- [ ] Колесо миші — масштаб, перетягування — рух карти.
- [ ] Кнопка шарів праворуч угорі → **Топокарта** / **Супутник**: обидва показують місцевість.
- [ ] Наведи мишку на позначку → підпис («Старт — …», «Ночівля 1»).
- [ ] Кнопка ⛶ — карта на весь екран.

## 10. Mapy.com
У плані натисни **«Увесь маршрут»**, потім **«день 1»**.
- [ ] Відкривається туристична карта з маршрутом через наші точки.
- [ ] Унизу «Elevation profile» / «Výškový profil»: підйом і спуск; наводиш на графік — видно місце на карті.

## 11. Трек у телефоні
1. У Finder: `demo-vault/Плани/<назва> — маршрут.gpx` → AirDrop на телефон.
2. Відкрий у **Mapy**, **Organic Maps** або **OsmAnd**.
- [ ] Видно трек по днях і точки (старт, ночівлі, фініш, вершини).

## 12. Запасна модель, коли хмара не відповідає
Імітуємо збій хмари, не чіпаючи `.env` (неіснуюча модель лише для цього запуску):
```bash
OPENROUTER_MODEL=nema/takoi-modeli uv run plast-agent --chat
```
- [ ] У Терміналі: **«↪ … → перемикаюсь на ollama/plast-gemma»**, план складається.
- [ ] У плані внизу записано, що була заміна моделі.

## 13. Перевірка без інтернету одним рядком (для кількох запитів)
```bash
uv run python scripts/offline_check.py "Запити/Тест — Говерла старші.md" "Запити/Тест — Горгани 3 дні.md"
```
- [ ] Біля кожного запиту ✓ і рядок «Готово: …».

## 14. Сторінка плану в браузері
1. Після будь-якого прогону агента в останньому рядку є `Сторінка плану у браузері: uv run plast-web → /plan/…`.
2. У Терміналі:
   ```bash
   cd "/Users/nazarobod/Desktop/Second Brain/01-Education/kse-agentic-ai-school/assignments/lab1-mcp-integration/plast-hike-planner"
   ```
   ```bash
   uv run plast-web
   ```
   Браузер відкриється сам на списку планів. Зупинити: Ctrl+C.
3. Що перевірити на сторінці плану:
   - немає англійських фраз, кодів на кшталт `ENDS_ON_TOP` і номерів на кшталт `r8613349` / `w30` (вони є лише
     в «Показати технічні деталі» внизу — це для захисту);
   - карта з днями різними кольорами; наведи мишу на профіль висот — на карті рухається точка;
   - картки днів: зелена смуга ходу, бурштинова — якщо прихід пізніше, ніж за 3 год до заходу;
   - «⬇ Трек GPX» завантажує файл; «Mapy.com ↗» відкриває маршрут;
   - кнопка ◐ угорі праворуч перемикає світлу й темну тему; галочки в документах лишаються після оновлення;
   - вузьке вікно (як телефон): усе в одну колонку, нічого не вилазить убік.
4. Без інтернету: замість карти має бути малюнок маршруту з підписом, решта сторінки працює.

## Після тестів
